================================================================================
1. PROJECT OVERVIEW & GOALS
================================================================================
1. Transformation Goal:
   - Convert the current personal portfolio (provash_dev-main) into a modern, 
     high-converting Digital Agency / Business Website.
   - Core Services Offered:
     * Full-Stack Web Application Development
     * YouTube Automation (Content Strategy, Video Editing, Channel Management)
     * Social Media Marketing (SMM, Paid Ads, Brand Growth)
     * Technical SEO & Content Marketing
     * 1-on-1 Strategy & Consulting

2. Portfolio Preservation:
   - The existing personal portfolio design, tech stack showcase, and project 
     components will NOT be discarded.
   - All existing portfolio assets and layouts will be migrated to a dedicated 
     page route: `/portfolio` (and subroutes like `/portfolio/all-projects`, 
     `/portfolio/featured-work`).
   - The primary Navbar will feature a prominent "Portfolio" link allowing visitors 
     and recruiters to inspect personal credentials anytime.

3. Complete Architectural Upgrade:
   - Frontend: Upgraded to TypeScript, Bun runtime, TanStack Query, Zod, 
     Shadcn UI, and Biome (exact mirror of l2b7-project-ph-healthcare-frontend 
     and b7a7-a6-developer-frontend).
   - Backend: Dedicated modular API server powered by Express, TypeScript, 
     Prisma ORM, and PostgreSQL, following the Level-2 PH Healthcare pattern.

2. COMPREHENSIVE TECH STACK SPECIFICATIONS
================================================================================

--------------------------------------------------------------------------------
A. FRONTEND STACK (Agency + Portfolio)
--------------------------------------------------------------------------------
- Runtime & Package Manager: Bun (bun.lock)
- Framework: Next.js 16 (App Router) + React 19
- Language: TypeScript 5 (Strict type checking, tsconfig.json)
- Linter & Code Formatter: Biome (biome.json) - Fast, modern ESLint/Prettier alternative
- Styling: Tailwind CSS v4 + @tailwindcss/postcss
- Component Library: Shadcn UI + @base-ui/react + Radix Primitives
- Icons: Lucide React + React Icons
- Server State & API Cache: @tanstack/react-query (v5)
- Form Management: @tanstack/react-form + React Hook Form
- Validation: Zod (v4 / latest)
- HTTP Client: ofetch / axios / native fetch wrapper
- Animations: tw-animate-css + Lucide animations

--------------------------------------------------------------------------------
B. BACKEND STACK (RESTful Modular API)
--------------------------------------------------------------------------------
- Runtime & Package Manager: Bun / Node.js
- Framework: Express.js (v4/v5) with TypeScript
- Language: TypeScript 5 (tsconfig.json)
- Database & ORM: PostgreSQL with Prisma ORM
- Request Validation: Zod schema validation middleware
- Security & Auth: JWT (Access Token + Refresh Token), bcryptjs, Helmet, CORS
- File Uploads: Multer + Cloudinary (or Supabase Storage)
- Email Notifications: Nodemailer with EJS email templates
- Error Handling: Centralized AppError + globalErrorHandler + catchAsync wrapper
- Response Standard: Consistent JSON output format via sendResponse utility

4. DATABASE MODEL SPECIFICATION (Prisma Schema)
================================================================================

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

generator client {
  provider = "prisma-client-js"
}

enum Role {
  SUPER_ADMIN
  ADMIN
  CLIENT
}

enum ServiceCategory {
  WEB_DEVELOPMENT
  YOUTUBE_AUTOMATION
  SOCIAL_MEDIA_MARKETING
  SEO_OPTIMIZATION
  STRATEGY_CONSULTING
}

enum InquiryStatus {
  PENDING
  IN_PROGRESS
  CONTACTED
  RESOLVED
  CANCELLED
}

model User {
  id        String   @id @default(uuid())
  name      String
  email     String   @unique
  password  String
  role      Role     @default(CLIENT)
  phone     String?
  avatar    String?
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  inquiries Inquiry[]
}

model Service {
  id          String          @id @default(uuid())
  title       String
  slug        String          @unique
  category    ServiceCategory
  shortDesc   String
  fullDesc    String          @db.Text
  icon        String?
  coverImage  String?
  features    String[]        // Array of bullet points/features
  startingPrice Decimal?      @db.Decimal(10, 2)
  isFeatured  Boolean         @default(false)
  isActive    Boolean         @default(true)
  createdAt   DateTime        @default(now())
  updatedAt   DateTime        @updatedAt

  inquiries   Inquiry[]
}

model PortfolioProject {
  id          String   @id @default(uuid())
  title       String
  slug        String   @unique
  description String   @db.Text
  category    String   // e.g. "Full-Stack Web", "SaaS", "Automation"
  thumbnail   String
  gallery     String[] // Additional screenshots
  liveUrl     String?
  githubClient String?
  githubServer String?
  technologies String[] // e.g. ["Next.js", "TypeScript", "Prisma", "PostgreSQL"]
  featured    Boolean  @default(false)
  order       Int      @default(0)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}

model Inquiry {
  id          String        @id @default(uuid())
  name        String
  email       String
  phone       String?
  serviceId   String?
  service     Service?      @relation(fields: [serviceId], references: [id])
  userId      String?
  user        User?         @relation(fields: [userId], references: [id])
  budget      String?
  timeline    String?
  message     String        @db.Text
  status      InquiryStatus @default(PENDING)
  notes       String?       @db.Text // Admin internal notes
  createdAt   DateTime      @default(now())
  updatedAt   DateTime      @updatedAt
}

model Testimonial {
  id          String   @id @default(uuid())
  clientName  String
  clientRole  String   // e.g. "Founder, TechCorp"
  clientAvatar String?
  companyName String?
  rating      Int      @default(5)
  feedback    String   @db.Text
  serviceType String?
  isPublished Boolean  @default(true)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}

5. REST API ENDPOINTS SPECIFICATION
================================================================================

1. Authentication Module (`/api/v1/auth`):
   - POST /auth/login               -> Sign in user/admin, returns JWT tokens
   - POST /auth/register            -> Sign up client
   - POST /auth/refresh-token       -> Issue new access token
   - POST /auth/forgot-password     -> Send reset OTP/link via email
   - POST /auth/reset-password      -> Reset credentials

2. Services Module (`/api/v1/services`):
   - GET    /services               -> Public: List all active services (filterable)
   - GET    /services/:slug         -> Public: Get detailed service by slug
   - POST   /services               -> Admin: Create new service offering
   - PATCH  /services/:id           -> Admin: Update service details
   - DELETE /services/:id           -> Admin: Deactivate/delete service

3. Portfolio Module (`/api/v1/portfolio`):
   - GET    /portfolio              -> Public: List all portfolio projects
   - GET    /portfolio/featured     -> Public: Get featured projects for homepage teaser
   - GET    /portfolio/:slug        -> Public: Get project case study
   - POST   /portfolio              -> Admin: Add new portfolio project
   - PATCH  /portfolio/:id          -> Admin: Update project
   - DELETE /portfolio/:id          -> Admin: Remove project

4. Inquiries / Leads Module (`/api/v1/inquiries`):
   - POST   /inquiries              -> Public: Submit client consultation / quote form
   - GET    /inquiries              -> Admin: List all client leads with pagination & filters
   - GET    /inquiries/:id          -> Admin: View full inquiry details
   - PATCH  /inquiries/:id/status   -> Admin: Update status (PENDING, RESOLVED, etc.)
   - DELETE /inquiries/:id          -> Admin: Delete spam / invalid lead

5. Testimonials Module (`/api/v1/testimonials`):
   - GET    /testimonials           -> Public: List verified client reviews
   - POST   /testimonials           -> Admin: Add client testimonial
   - PATCH  /testimonials/:id       -> Admin: Edit testimonial
   - DELETE /testimonials/:id       -> Admin: Delete review
