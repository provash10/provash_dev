6. সাধারণ সমস্যা ও সমাধান (TROUBLESHOOTING)
================================================================================
সমস্যা ১: "Error: connect ECONNREFUSED 127.0.0.1:3000"
সমাধান: ফ্রন্টএন্ড নেক্সট.জেএস সার্ভার চালু নেই। টার্মিনালে `bun run dev` চালান।

সমস্যা ২: "404 Not Found"
সমাধান: রাউট পাথে কোনো টাইপো হয়েছে কিনা দেখুন। এই কালেকশনে প্রোভাইড করা প্রতিটি পাথ 
Next.js App Router-এর সাথে শতভাগ মিলে যায়।

সমস্যা ৩: ইন্টিগ্রেশন ফোল্ডারের রিকোয়েস্টে "ECONNREFUSED 127.0.0.1:5000"
সমাধান: ব্যাকএন্ড সার্ভার চালু নেই। `provash_dev-backend` ফোল্ডারে গিয়ে `bun run dev` চালান।
